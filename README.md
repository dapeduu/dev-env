# Dev-Env Setup Script

## Overview

A comprehensive bash script to set up a complete development environment on Ubuntu/Debian-based systems.

## Features

- 🔤 Install Nerd Fonts (JetBrainsMono)
- 🐚 Configure ZSH with extensions
- 🧰 Install ASDF version manager
- 💻 Install Visual Studio Code
- 🐳 Install Docker
- 🇧🇷 Fix cedilha input method
- 🔧 Configure Git

## Quick Install

```bash
wget -O - https://raw.githubusercontent.com/dapeduu/dev-env/refs/heads/main/install.sh | bash
```

## Prerequisites

- Ubuntu or Debian-based Linux distribution
- Bash shell
- Internet connection

## Customization

Fork the repository and modify the `install.sh` script to suit your specific development needs.

## What This Script Does

1. Checks and installs system dependencies
2. Sets up development tools
3. Configures input methods
4. Prepares your environment for coding

## Caution

- Review the script before running
- Backup your existing configuration files
- Run at your own risk
